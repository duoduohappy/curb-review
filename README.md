# 路证 / Curb Review

用于演示“每周持续新增道路图片 → AI 辅助筛选 → 人工复核 → 导出”的本地项目。Python 标准库 + 原生 HTML/CSS/JS + SQLite，无 pip/npm 依赖，无 API Key，无付费接口。本地模式下图片保存在本机、模型请求仅发送至本机 Ollama；Render 云端模式的数据处理方式见在线部署说明。

## 启动

安装 Python 3.10+，双击 `start.bat`，然后打开 http://127.0.0.1:18765 。或在项目目录运行 `python server.py`。关闭终端或按 Ctrl+C 停止。若端口被占用，PowerShell 先运行 `$env:CURB_PORT='18766'`，再运行服务并使用新端口。

## 无模型演示（立即可用）

1. 点击“加载流程演示”，生成 12 张合成道路示意图。
2. 切换“证据候选 / 待判断 / 未发现线索”，打开图片查看证据说明。
3. 选择“证据可用 / 排除 / 仍需补充材料”，输入备注并保存。
4. 切换“待人工复核”，查看尚未审核的记录；点击“导出全部记录”，可用 Excel 打开 CSV。
5. 重启服务，记录仍然存在。重复加载演示不会新增重复示例。

**示意图和分析说明均为预设，页面与导出文件明确标记；它们不是模型识别结果，也不能用于证明识别准确率。用户提供的是岗位与聊天截图，并非道路测试集，因此不将其当作识别样本。**

## 免费本地模型 / 真实图片分析

1. 从 https://ollama.com/download 安装 Ollama 并启动。
2. 在终端运行 `ollama pull gemma3:4b`。首次需联网下载数 GB 模型，运行占用本机内存与算力；速度取决于硬件。无按次 API 费用，仍有硬件、电力成本，模型按其许可证使用。
3. 页面顶部显示模型就绪后，导入真实 JPG / PNG / WEBP 图片。建议先用少量清晰图片验证，单张不超过 12 MB。
4. 后台逐张调用 Ollama。候选结果依赖车辆、标志/标线、空间关系四项结构化观察；不输出未经验证的定位框和置信度。
5. 失败任务会显示错误，安装模型或解决超时后在详情点击“重新排队”。每次调用超时 240 秒，失败不会伪造结果。

自定义模型：PowerShell `$env:CURB_MODEL='其他已安装的视觉模型名称'`，再启动服务。必须具备图片输入和 JSON 输出能力。默认 gemma3:4b 是免费本地演示起点，并非该业务效果最优的承诺。Gemma 3 的 270m / 1b 是纯文本模型，不能替代 4b 视觉版本。

官方参考：[Gemma 3 模型说明](https://ollama.com/library/gemma3:4b)、[Ollama Chat API](https://docs.ollama.com/api/chat)。

## 每周更新如何演示

先把批次名设成“第 1 周”并上传照片，再改成“第 2 周”上传同一张照片和新照片。SHA-256 相同的原始文件跳过，仅新增图片入队。截图、重新压缩、裁剪后的相似图片不属于精确重复，仍会入库。重复照片保留首次入库批次，本版没有跨批次出现次数台账。

数据位于 `data/review.db` 与 `data/images/`，SQLite 保存原图哈希、首次批次、模型名、分析结果、复核结论、备注和时间。服务重启时，处理中断的任务重新排队。可通过 `CURB_DATA` 指定其他数据目录。备份时先停止服务，再复制整个 data 文件夹。

## 范围与下一步

这是单机演示版本：手动按周导入，无无人值守定时采集；串行推理；全量列表，无分页；无多用户权限、模型版本完整审计或生产级文件校验。图片类型按文件签名初步校验，无法解码的内容由模型服务报错。适合少量到数百张图片的流程试用，不宣称已经验证大规模吞吐。

候选只表示可见证据较完整，不是违停认定；“未发现线索”仍要抽查，模型可能漏检。没有真实道路测试集，尚无准确率/召回率数据。应准备白天、夜间、雨雪、遮挡、无标志等人工标注样本，先测候选精确率、相关证据漏检率、平均每图处理时间及复核耗时，再选择模型或增加检测器。每周新图只做推理，人工反馈不会自动训练模型。

## 验证

运行 `python -m unittest discover -s tests -v`。覆盖跨批次去重、数据持久化、演示隔离标识、人工复核、CSV 公式转义、保守分类、异常输出、非法上传、任务恢复，以及使用本地 mock 服务验证真实模型适配器的图片传输。Mock 不代表真实模型效果。

## 模拟数据包

首次使用空数据库启动会自动加载 12 张模拟样例。已有数据库可点击“加载流程演示”。包含两周的 PNG 上传文件和预设答案，详见 `samples/README.md`。应用运行不需要 Pillow；仅重新生成程序绘制图片时才需 Pillow。
